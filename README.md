# Yahav Mor · Portfolio

**Live site:** https://yahavmor.github.io

Personal portfolio of Yahav Mor, full-stack developer (React, Node.js, MongoDB) and Make automation builder.

## What's inside

- **Bilingual, English and Hebrew.** One page, a language switch in the header, full RTL layout in Hebrew. Link straight to a language with `#en` or `#he`.
- **A contact form that runs a real automation.** Submissions go to a Make webhook, land in Google Sheets, send me an alert in Gmail, and send the visitor a confirmation email in their language. The "Fig. 1" diagram at the top of the page shows that flow and animates it on a real submit.
- **No framework, no build step.** Plain HTML, CSS and vanilla JavaScript in a single file, with light and dark themes and `prefers-reduced-motion` support.
- **CV** as a one-page PDF (`cv.pdf`).
